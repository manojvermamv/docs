# AI Agent Tools: Repos and Alternatives
*Last checked: 17 Nov 2026*

## About This List
* **Main List:** the repos currently in use, ordered dev tools first, then docs, then video and animation.
* **Alternatives:** repos that may replace a Main List repo. Each one should be mature, updated regularly, and judged better on both documentation and actual codebase, not on what its docs claim.
* **Skipped:** candidates that were considered but left out because they are outdated or their update date could not be confirmed.
* **Verification status:** repo pages and release lists were re-checked on 17 Nov 2026 where GitHub would load them, and through release trackers and listings where it would not. Codebase-level comparisons have not been done yet.
* **Not re-checked this round (carried over from earlier):** star counts for SEED, PAUL, Skillsmith, BASE, Hypit, OpenSpec and BMAD-METHOD, and the dates for the Skipped repos not marked "re-checked".
* **Dates and stars:** update ages are rounded from the check date above. Star counts are approximate and come from different dates (Jun–Nov 2026), so use them as a rough guide only.
* **Updating:** when an Alternative proves better, it moves up into the Main List and the repo it replaces moves down into Alternatives. When a Skipped repo gets a recent update, it moves up into Alternatives.
